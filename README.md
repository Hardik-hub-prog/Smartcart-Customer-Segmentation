SmartCart Customer Segmentation System

📌 Project Overview

The SmartCart Customer Segmentation System is an end-to-end Unsupervised Machine Learning project that segments e-commerce customers into meaningful groups based on their purchasing behavior and demographic characteristics.

Using a dataset of 2,240 customer records with 22 features, this project demonstrates the complete machine learning workflow—from data preprocessing and feature engineering to clustering, dimensionality reduction, visualization, and customer profiling. The objective is to help businesses better understand their customers and support data-driven marketing strategies.

🎯 Problem Statement

SmartCart is a growing e-commerce platform serving customers across multiple countries. T

Currently, SmartCart uses generic marketing and engagement strategies for all customers, without clearly understanding different customer behaviour patterns. This results in inefficient marketing
, missed opportunities to retain high-value customers, and delayed identification of churn-prone users.
